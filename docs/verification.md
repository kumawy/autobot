# Проверки v1.1

Выполнены локально 1 октября 2026 года (Asia/Almaty), macOS, **Node.js 24.21.0**.

- `npm run check`: TypeScript, ESLint и **244 теста в 14 файлах** прошли.
- `npm run build` прошёл. Для собранных app и worker отдельно проверены HTTP health/readiness, HTML/CSS/JS и сохранение heartbeat.
- `npm audit --omit=dev`: известных уязвимостей не найдено на момент проверки.
- `npm run demo` запускает PostgreSQL 18.4, применяет все 5 миграций, seed и отдельные процессы app/worker. После перезапуска данные сохраняются.
- `npm run check:production` в demo возвращает `ready:false` и exit1: отсутствуют реальные credentials, условия демонстрационные, нужны ручные проверки аккаунтов. Отчёт сохранён локально в `.local/production-readiness.json`.

Интеграционные тесты используют настоящую отдельную PostgreSQL с реальными миграциями и ограничениями. Внешние HTTP/API подменяются контролируемыми ответами; это позволяет воспроизводить потерянный ack, гонки и ошибки без настоящих списаний/отправок.

## Проверка прежней базы

Перед миграцией локальная PostgreSQL была остановлена и сохранена в `.local/backups/pre-v1.1-postgres.tar.gz`. Архив затем восстановлен в отдельный временный каталог и порт; к копии применены все миграции v1.1. Сохранены 1 заказ,1 платёжная попытка,1 оплаченный заказ на 20000 KZT и 21 задание. Новые внешние действия не создавались. Подробности — `.local/backups/restore-check.json`. Рабочая база с текущими демонстрационными проверками не подменялась восстановленной копией.

## Ручная проверка интерфейса

В Safari на настольном экране пройдены первый вопрос и выбор языка, заказ RU, показ privacy notice и отдельное согласие, выбор диска, доставка/итог, заморозка суммы и тестовая оплата. Фраза «я оплатил» оставляет PAYMENT_PENDING; подписанный mock callback даёт PAID, подтверждение клиенту и завершённые задания Sheets/Telegram.

Проверены обращение менеджеру, claim 1001, Reply в нужный диалог, close, повторное обращение и явный возврат клиента к боту. STOP отключает инициативные уведомления, сохраняя PAID. Исправлены подписи действий, автор ответа менеджера и отображение статуса старого ticket.

Для v1.1 мобильный viewport отдельно не проверялся. Docker на этой машине отсутствует, поэтому контейнерная сборка и `docker compose up` не выполнялись. Реальные Meta, OpenAI, Freedom Pay, Google Sheets и Telegram не подключались; настоящих списаний и сообщений не было. Требования к проверке аккаунтов перечислены в [production-readiness.md](production-readiness.md).
